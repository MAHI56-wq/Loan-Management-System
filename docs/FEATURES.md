# Features

## Core
- Customer add/list/update/delete
- Officer add/list/update/delete
- Loan application and monthly installment calculation
- Loan search by ID, customer name, type, or status
- Loan approval/rejection
- Officer assignment
- Payment recording and automatic completion
- Payment history
- Dashboard/report summary
- Notifications through Observer pattern
- Validation and SQLite persistence

## Added Enhancements
1. Customer CRUD
2. Officer CRUD
3. Loan search
4. Officer assignment UI
5. Dashboard/report cards
6. Payment history
7. Automatic loan completion
8. Interest strategy selection through Factory + Strategy
